☁️ OneDrive Sync Setup (Staff/Admin only)

Note: this connects your firm's own OneDrive as the backup/sync store — it is intentionally restricted to Admin/staff logins only. Client logins (e.g. Archit, Dilip, etc.) never see a "Connect OneDrive" option and never receive this shared file, since it contains every client's data. Clients continue to see whatever's already saved to the device/browser they're using. One-time setup: requires an Azure AD "App Registration" Client ID (ask your admin/IT for this).

Steps: Save your Client ID → Connect OneDrive (signs you into Microsoft) → Create Data File → Create Shareable Edit Link → Save OneDrive Settings again to store the link → share the Client ID + Link with your app maintainer. Every teammate then clicks "Connect OneDrive" in the header with their own Microsoft account to read/write the same file.

⚡ Auto-Publish Setup (GitHub only, no external hosting)

One-time setup so every import/change automatically publishes each client's own file straight to this repo — no manual export, no third-party server. The token below is sensitive: it is saved only in this browser's local storage, is never committed to the repo, and is never sent to anyone else. Use a token scoped only to this one repository (fine-grained token, Contents: Read and write) rather than a broad all-repo token.

👥 Per-Client Data Export (manual fallback)

If Auto-Publish above isn't set up yet, use this instead: for each client below, click "Export JSON" to download/copy their data, then send it to your app maintainer to publish manually. Once Auto-Publish is configured, this is no longer needed for day-to-day use.

📥 Step 1: Download Template

Click below to download a template with sample data. It opens directly in Excel — fill it in and save.

Columns: Date, Transaction, Amount, Dr/Cr, Name — e.g. 2026-08-01, Amazon Purchase, 5000, Dr, John Doe. The Name column maps each transaction to the person it belongs to.

📤 Step 2: Upload Your File

CSV files always work. .xlsx files work only if your network allows loading the Excel library — if upload fails, save your file as CSV in Excel (File → Save As → CSV) and upload that instead.
